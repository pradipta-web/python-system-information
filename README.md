# Python System Information Tool

A simple Python application that displays basic system information.

## Features

- Display computer hostname.
- Detect operating system.
- Display OS version.
- Show system architecture.
- Display processor information.
- Show Python version.
- Display current working directory.

## Technologies

- Python 3
- Platform Module
- Socket Module
- OS Module

## Project Structure

```text
python-system-information/
├── app.py
├── requirements.txt
├── README.md
└── .gitignore
```

## Installation

Clone this repository:

```bash
git clone https://github.com/pradipta-web/python-system-information.git
```

Navigate to the project directory:

```bash
cd python-system-information
```

## Usage

Run the application:

```bash
py app.py
```
